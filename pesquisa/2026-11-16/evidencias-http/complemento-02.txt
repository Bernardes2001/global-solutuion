        <h2 class="pane-title">
      Dados abertos do Governo do Maranhão    </h2>
    
  
  <div class="pane-content">
    <div class="fieldable-panels-pane">
    <div class="field field-name-field-basic-text-text field-type-text-long field-label-hidden"><div class="field-items"><div class="field-item even"><p>O Governo do Estado do Maranhão é comprometido em incrementear continuamente a <strong>abertura dos dados, transparência e as prestações das contas</strong> do governo. Este portal visa prover dados abertos atuais sobre o Governo do Estado.</p>
<p>O Portal de Dados Abertos reúne conjuntos de dados de todas as órgãos e empresas públicas estaduais. Com os recursos deste Portal, é possível construir aplicativos, visualizações de dados e obter informações essenciais sobre as políticas públicas e a administração do estado.</p>
<p>A Política de Dados Abertos do Poder Executivo Estadual foi instituída pelo <a href="http://app.stc.ma.gov.br/legisla/consulta/publicacao/7143">Decreto Estadual n° 39.070, de 17 de maio de 2024</a></p>
<p>Em conformidade com a Política de Dados Abertos, foi elaborado o Plano de Dados Abertos para o Estado do Maranhão <a href="https://www.transparencia.ma.gov.br/storage/anexos-portal/anexo_2025-08-20_17-39-15_b61e4a4736673c70930a40fef15d1bcb4e1b4ecf240b4183e4ecf9d86a05f718.pdf">PDA - Plano de Dados Abertos do Estado do Maranhão</a></p>
